# 설치 안내 (교사 개인 구글 계정, 약 15분)

Google Cloud 설정과 카드 등록은 필요 없습니다. 개인 gmail 계정 하나로 진행합니다.

## 1. 서버(GAS) 올리기
1. Chrome에서 **개인 구글 계정**으로 로그인된 상태인지 확인합니다.
2. https://script.google.com/home/usersettings 에서 **Google Apps Script API**를 "사용"으로 바꿉니다. (업로드 도구 clasp를 쓰기 위해서이며, 한 번만 하면 됩니다.)
3. 아래 명령을 차례로 실행합니다. `clasp login`을 실행하면 브라우저가 열리니, 개인 계정으로 로그인하고 허용을 누릅니다.
   ```bash
   npm install -g @google/clasp
   clasp login
   cd C:/claude_code/classroom-ocr
   clasp create --type standalone --title "과제 제출 서버" --rootDir gas
   git checkout gas/appsscript.json
   clasp push --force
   ```
   - `clasp create`가 `gas/appsscript.json`을 기본값으로 덮어써요. 그래서 바로 다음 줄의 `git checkout`으로 원래 파일을 되돌립니다.

## 2. 처음 한 번 설정 (`setup`)
1. `clasp open-script`를 실행하거나, script.google.com에서 "과제 제출 서버" 프로젝트를 엽니다.
2. 위쪽 함수 목록에서 **setup**을 고르고 **실행**을 누릅니다.
3. 권한 요청 창이 뜨면 허용합니다. "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요. 직접 만든 스크립트라서 나오는 정상 경고입니다.
4. 아래 실행 로그에 두 가지가 나옵니다.
   - **데이터 시트** 주소: 내 드라이브에 "과제 제출 DB" 시트와 "과제 제출" 폴더가 생겼어요.
   - **교사 접속 링크**: 이 링크는 다른 사람에게 보여 주지 마세요. 링크를 아는 사람은 교사 화면에 들어올 수 있습니다.

## 3. 웹앱으로 배포
1. 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형은 **웹 앱**, 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 정합니다.
3. **배포**를 누르면 나오는 **웹 앱 URL**(`…/exec`로 끝남)을 복사합니다.
4. `web/config.js`의 `API_URL`에 그 URL을 붙여 넣습니다.
- 나중에 서버 코드를 고치면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포하세요. URL은 그대로 유지됩니다.

## 4. 앱 화면 올리기 (GitHub Pages)
1. `web/config.js` 변경을 커밋하고 `main`에 반영합니다. PR을 병합하면 됩니다.
2. GitHub 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
3. Actions 탭에서 배포가 끝나면 앱 주소는 `https://goodth777.github.io/classroom-ocr/`입니다.
   - 주소가 다르면 `gas/Api.js` 맨 위의 `APP_URL`을 맞게 고치고 다시 배포하세요(교사 링크를 만드는 데 씁니다).

## 5. 사용 시작
1. **교사**: PC에서 교사 접속 링크를 엽니다. 주소창 오른쪽의 **설치**를 누르면 주소창 없는 앱 창으로 쓸 수 있어요.
2. **＋ 새 반 만들기** → **학생 명단** 탭 → **＋ 명단 붙여넣기**(엑셀이나 나이스에서 번호·이름 두 칸 복사) → **PIN 카드 인쇄**.
3. 수업 시간에 **⛶ 크게 보기**로 수업 코드를 화면에 띄웁니다.
4. **학생**: 휴대폰으로 앱 주소를 열고 **홈 화면에 추가**한 뒤, 그 앱에서 수업 코드 → 번호 → PIN을 입력합니다. 다음부터는 자동으로 들어갑니다.
5. **과제 현황** 탭의 **＋ 새 과제**로 과제를 냅니다.

## 알아 두기
- 학생 답안과 사진은 선생님 드라이브의 "과제 제출" 폴더와 "과제 제출 DB" 시트에 저장돼요. **📊 원본 시트 열기**로 언제든 직접 볼 수 있습니다.
- 학생이 휴대폰을 잃어버렸거나 다른 사람이 들어간 것 같으면, 학생 명단에서 **재발급**을 누르세요. 그 학생의 기존 기기는 모두 로그아웃됩니다.
- 개인 계정은 동시 처리량에 한도가 있어요. 한 반이 동시에 제출하면 몇 초씩 기다릴 수 있고, 앱이 자동으로 다시 시도합니다.
