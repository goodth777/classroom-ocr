# 손글씨 과제 제출 앱 — 설계 (v2: 클래스룸 없이, 개인 계정)

> v1(구글 클래스룸 연동, 학교 Workspace + Google Cloud 설정)은 2026-10-08 폐기했습니다. 교육청 계정 관리자 제한과 Cloud 설정 부담 때문입니다. v1 기록은 git 이력에 있습니다.

## 목표
- **학생(모바일 우선)**: 처음 한 번만 수업 코드 + 번호 + PIN으로 참여하고, 이후에는 자동으로 입장합니다. 과제를 골라 손글씨를 촬영하면 OCR로 글자를 읽고, 학생이 직접 고친 뒤 제출합니다. 직접 입력도 할 수 있어요.
- **교사(웹 우선)**: 반과 학생 명단을 관리하고, 과제를 냅니다. 학생 × 과제 표 한 화면에서 모든 제출물을 확인하고 전체를 내려받습니다.
- **조건**: 무료, 카드 등록 없음, **교사 개인 구글 계정 하나로 운영**, 학생은 구글 계정이 필요 없음, Google Cloud 설정 없음.

## 구조

```
PWA (GitHub Pages, 무료)                    GAS 웹앱 (교사 개인 계정, "나로 실행", 접근: 모든 사용자)
 ├ 학생: 참여 · 과제 · 촬영 · 제출   ──POST──►  doPost(JSON) ─┬ 인증 (기기 열쇠 / 교사 키)
 └ 교사: 반·명단 · 과제 현황 · 내보내기                         ├ OCR: 드라이브 이미지→문서 변환
                                                               ├ 구글 시트 (데이터베이스)
                                                               └ 드라이브 폴더 (제출 사진)
```

- 화면은 PWA가 보여 주고 GAS는 데이터만 주고받습니다. 그래서 GAS 경고 띠가 없고, 설치하면 주소창 없는 앱 창으로 열립니다.
- PWA는 `fetch(웹앱 URL, {method:'POST', body: JSON 문자열})`로 호출합니다. `Content-Type: text/plain`이라 CORS 사전 요청이 생기지 않습니다. 응답은 `ContentService` JSON입니다.
- 모든 작업(OCR, 시트, 드라이브)은 **교사 계정 권한**으로 실행됩니다. 학생 드라이브는 쓰지 않습니다.
- 설정은 `web/config.js`의 `API_URL`(웹앱 주소) 하나뿐입니다.

## 데이터 (교사 드라이브의 구글 시트 1개 + 폴더 1개)
`setup()`을 한 번 실행하면 시트 "과제 제출 DB"와 폴더 "과제 제출"을 만들고, 교사 키를 발급합니다.

| 시트 | 열 |
|---|---|
| Classes | id, name, section, subject, code, created |
| Students | id, classId, number, name, pin, created |
| Devices | tokenHash, studentId, created, lastSeen |
| Assignments | id, classId, title, description, due(YYYY-MM-DD), created |
| Submissions | id, assignmentId, studentId, text, photoIds(쉼표 구분), submittedAt, late |

- 제출은 (과제, 학생)마다 한 줄입니다. 다시 제출하면 그 줄을 덮어씁니다.
- 사진은 `과제 제출/{반}/{과제}/` 폴더에 JPEG 파일로 저장하고, 교사 화면이 요청할 때만 base64로 보내 줍니다.
- 시트에 쓰는 작업은 `LockService`로 한 번에 하나씩만 실행합니다.
- 교사는 "시트 열기"로 원본 시트를 언제든 직접 볼 수 있습니다.

## 인증
- **학생 참여**: `join(code, number, pin)` → 맞으면 무작위 32바이트 **기기 열쇠**를 발급합니다. 시트에는 SHA-256 해시만 저장하고, 기기에는 열쇠를 보관합니다(localStorage). 이후 모든 학생 요청은 열쇠로 확인합니다. 그래서 자동 입장이 됩니다.
- **PIN**: 교사가 발급합니다(4자리, 명단 붙여넣기 때 자동 생성). PIN을 5번 틀리면 그 학생은 10분 동안 잠깁니다(`CacheService`). PIN을 재발급하면 그 학생의 기기 열쇠가 모두 무효가 됩니다.
- **교사**: `setup()`이 만든 **교사 키**(무작위, Script Properties에 보관)를 처음 한 번 "교사 접속 링크"(`…/#/teacher?key=…`)로 열면 기기에 저장됩니다. 교사 요청은 모두 이 키로 확인합니다.
- **이 기기에서 나가기**: 학생은 프로필 메뉴에서 기기 열쇠를 지울 수 있습니다(공용 기기 대비).
- **아이폰 안내**: 사파리와 홈 화면 앱은 저장공간이 서로 달라서, 참여 첫 화면에서 "먼저 홈 화면에 추가하고 그 앱에서 참여"를 안내합니다.

## OCR (범용)
1. PWA가 사진을 긴 변 1600px, JPEG 품질 0.8로 줄여서 보냅니다(제출당 최대 5장).
2. GAS가 Drive 고급 서비스로 이미지를 Google 문서로 변환하며 OCR을 돌리고(`ocrLanguage: 'ko'`), 텍스트를 읽은 뒤 임시 문서를 지웁니다.
- 양식 인식은 하지 않습니다. 순서 뒤섞임과 첨삭 표시 섞임은 학생이 편집 화면에서 고칩니다.
- 2026-10-07 테스트: 한글·영어 손글씨 인식은 양호하고, 학생 철자를 고치지 않고 그대로 옮깁니다.
- OCR 호출은 함수 하나(`ocr_`)에 모아서, 나중에 CLOVA나 Cloud Vision으로 바꿀 수 있게 합니다.

## 화면 (2026-10-07~08 미리보기로 승인)
- **테마 C 옵시디언 에메랄드**(블랙 + 에메랄드), 글꼴 Pretendard, 카드·벤토, 화면당 주요 행동 하나.
- **학생 첫 참여**: 수업 코드(6자리) → 번호 확인(명단의 이름 자동 표시) → PIN(숫자 키패드) → 참여 완료("이 기기에 기억").
- **학생 홈**: 인사말·반, 벤토(제출 현황 링 / 미제출 / 다음 마감 D-day), 진행 중·완료 과제 카드, 하단 촬영 버튼, 프로필 메뉴(이 기기에서 나가기).
- **학생 과제**: 촬영 전 → 글자 읽는 중(스캔 애니메이션, 취소) → 수정(사진 썸네일·삭제·추가, 되돌리기, 사진 보기) → 제출 완료(영수증).
- **교사**: 반 전환 사이드바 + "새 반 만들기", 탭 두 개.
  - **과제 현황**: 벤토(전체 제출률 + 지난주 대비 / 미제출 / 최근 제출 / 다음 마감), 학생×과제 표(✓ 제출 · ! 지각 · 미제출, 마감일, 학생 검색, 학생별 제출 수), 제출 내용 패널(사진·텍스트·다음 학생), 새 과제(마감일·반 선택), CSV 내려받기, 시트 열기.
  - **학생 명단**: 수업 코드 카드(크게 보기·복사·새 코드), 참여 현황, 명단 표(번호·이름·PIN 보기·참여 여부·마지막 제출·PIN 재발급), 명단 붙여넣기(엑셀·나이스 번호·이름 두 칸), PIN 카드 인쇄.
- **앱 아이콘 A 스캔 시트**: 파비콘 32, 홈 화면 192·512(마스크형 여백), 애플 터치 180, 아이폰 시작 화면(주요 기종), 안드로이드 시작 화면은 manifest(배경 #0a0c0b)로 자동 생성.

## 오류 처리
- OCR이 실패하거나 시간이 초과되면 직접 입력으로 넘어가고, 사진은 유지합니다.
- 편집 중인 글은 기기에 임시 저장하고, 제출이 성공하면 지웁니다.
- 기기 열쇠가 무효가 되면(PIN 재발급, 학생 삭제) 참여 화면으로 돌아갑니다.
- GAS 동시 실행 한도에 걸리면 앱이 잠시 뒤 자동으로 한 번 다시 시도합니다.

## 알려진 한계
- 개인 계정 GAS는 동시 실행 수와 하루 처리량에 한도가 있습니다. 한 반이 동시에 제출하면 몇 초씩 기다릴 수 있습니다.
- 학생 답안과 사진은 교사 개인 드라이브에 저장됩니다(학교 방침 확인 필요).
- PIN을 아는 다른 사람은 그 학생으로 참여할 수 있습니다. 숙제 제출 용도 기준의 보안입니다.
