# 학번 · 클래스 종류별 설문 · 선택 삭제 · 링크/첨부 · 이름 가리기

작성: 2026-10-09 · 상태: 승인됨(채팅) · 순서: ④ → ① → ② → ③ → ⑤

## ④ 학번
- `Students`에 `sno`(5자리 학번) 칸. 기존 학생은 빈칸.
- 명단 붙여넣기: 줄마다 `학번 이름`(5자리) 또는 예전 `번호 이름`(1~3자리). 담임 클래스의 번호 = 학번 끝 두 자리. 수업 클래스의 번호 = 학번 끝 두 자리(표시는 학번).
- 기존 명단에 학번 채우기: 같은 클래스에서 이름이 하나뿐인 학생은 학번을 채움(참여·제출·PIN 유지). 같은 이름이 둘 이상이면 교사가 고르는 창. 처음 보는 이름은 새로 추가.
- PIN은 학번당 하나: 새로 추가할 때 다른 클래스에 같은 학번이 있으면 그 PIN을 씀. 재발급은 같은 학번 모든 행에 적용(확인 문구). PIN 실패 잠금 키는 학번(없으면 학생 id).
- 참여: 수업 코드 + 학번 5자리(또는 번호) + PIN. `peek`/`join`은 5자리면 `sno`, 아니면 `number`로 찾음.
- 교사 화면: 명단·과제 표·응답 목록에 학번 표시, 학번순 정렬(학번 없으면 번호). 학생 현황 패널에 같은 학번이 있는 다른 클래스.

## ① 클래스 종류별 설문
- 수업: 퀴즈·회신(탭 "퀴즈·회신"). 담임: 설문·회신(탭 "설문·회신"). 서버 `formPut`이 종류를 검사. 기존 수업 클래스 설문은 보기·응답 확인 가능.

## ② 선택 삭제
- 목록 필터(전체/초안/진행 중/마감) + "선택" 모드(체크칸, 전체 선택, 선택 삭제). 화면 즉시 반영, 서버는 뒤에서. 응답이 있으면 확인.

## ③ 링크·첨부
- 안내문·문항·공지·메시지 속 `http(s)://`를 링크로(새 탭, `rel="noopener"`).
- 첨부: 설문 제목 카드·문항·공지에 📎. GAS `upload {name, mime, data}` → 드라이브 '과제 제출/첨부' 폴더, 링크 공유 → `{id, name, mime, size}`. 학생: 이미지는 `https://drive.google.com/thumbnail?id=…&sz=w1200`로 표시, 그 외는 이름 + 열기(`https://drive.google.com/file/d/…/view`). 10MB/파일, 5개/곳.

## ⑤ 이름 가리기
- `peek`이 돌려주는 이름을 가운데 가림(`김*준`, 2글자는 `김*`, 4글자 이상은 처음·끝만). `join` 성공 후에만 전체 이름.
