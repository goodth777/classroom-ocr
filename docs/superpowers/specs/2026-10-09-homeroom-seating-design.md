# 담임 클래스 + 좌석 배치 설계

작성: 2026-10-09 · 상태: 승인됨(채팅) · 앞선 설계: `2026-10-07-classroom-ocr-submit-design.md`

## 1. 목표와 원칙

- 교사 화면의 클래스를 **수업 / 담임** 두 종류로 나누고, 담임 클래스에 **좌석 배치**를 넣는다.
- **속도가 최우선.** 좌석 배치의 모든 동작(구성, 끌어다 놓기, 고정, 무작위, 애니메이션, 인쇄)은 기기 안에서 끝나고 서버(GAS)를 기다리지 않는다. 서버에는 저장본만 뒤에서 보낸다(기기 먼저, 서버는 뒤에서 = A 방식).
- 화면 문구의 "반"은 **"클래스"** 로 바꾼다.

## 2. 클래스 종류

- `Classes` 시트에 `kind` 칸 추가: `homeroom`(담임) / 빈칸(수업). 기존 클래스는 모두 수업.
- "새 클래스 만들기" 대화상자에서 **담임 / 수업**을 고른다. 담임 클래스 수는 제한하지 않는다.
- 교사 사이드바: **담임** 묶음 위, **수업** 묶음 아래.
- 탭: 수업 = 과제 현황 · 학생 명단 · 메시지 / 담임 = **좌석 배치** · 학생 명단 · 메시지. 담임 클래스의 기본 탭은 좌석 배치.
- 학생 명단·수업 코드·QR·PIN·공지·메시지·푸시는 종류와 관계없이 그대로 쓴다. 학생은 클래스마다 따로 참여한다(학번 묶기 없음). 담임 클래스에 과제가 없으면 학생 홈에는 공지·메시지만 보인다.

## 3. 좌석 배치 화면

### 3.1 두 단계

1. **좌석 구성**: 행×열(2~8 × 2~8, 기본 6열×5행)을 고르면 모든 칸이 깔린다. 칸을 누를 때마다 **책상(초록 테두리) ↔ 빈칸(색 없음)**. "모두 책상 / 모두 비우기", **두 자리씩 붙이기**(두 열마다 통로) 켜기/끄기. 오른쪽에 책상 수·학생 수·남는 자리. 학생 이름은 보이지 않는다. "구성 끝 · 자리 배치로"로 2단계.
2. **자리 배치**: 무작위 배치, 끌어다 놓기, 고정, 떨어뜨릴 학생, 저장/불러오기, 인쇄.

- 처음 여는 클래스는 1단계부터 시작한다(전부 책상).
- 학생이 앉은 뒤 구성을 바꾸면, 남은 책상의 학생은 그대로, 없앤 책상의 학생만 "자리 없는 학생"으로 돌아간다. 행·열을 줄여 칸이 사라질 때도 같다.

### 3.2 보기

- **학생 보기**: 교탁이 위, 1행(앞줄)이 위. **교사 보기**: 교탁이 아래, 행과 열이 모두 뒤집힌다(180° 회전). 토글 즉시 바뀐다. 좌석 데이터는 하나이고 그리는 순서만 바뀐다.

### 3.3 자리 다루기 (2단계)

- **끌어다 놓기**(마우스·터치 둘 다, Pointer Events): 학생 → 다른 학생 자리 = 서로 바꿈, → 빈 책상 = 이동, 오른쪽 "자리 없는 학생" ↔ 책상 사이도 가능.
- 자리를 누르면 메뉴: **이 자리에 고정 / 고정 해제 · 자리 비우기**.
- **떨어뜨릴 학생**: 오른쪽 패널에서 두 학생을 골라 쌍을 만든다. 무작위 배치 때 앞·뒤·옆으로 붙지 않는다. 학생에게 보이는 화면(애니메이션)에는 나오지 않는다.
- 학생 수 > 책상 수면 무작위 전에 "N명이 앉을 자리가 없어요" 안내.

### 3.4 저장 / 불러오기

- **작업본**: 화면의 현재 상태. 바뀔 때마다 기기에 즉시 저장되고, 서버에는 마지막 변경 2초 뒤 한 번 보낸다. 다시 열면 기기 저장본으로 바로 그리고, 서버 것이 더 새로우면 바꿔 그린다.
- **저장**: 이름(기본 "10월 9일 배치")을 넣으면 작업본의 사본이 저장 목록에 생긴다(즉시, 서버는 뒤에서).
- **불러오기**: 저장 목록(최근 순)에서 골라 작업본을 그 내용으로 바꾼다. 불러온 저장본이 다음 무작위의 **기준 배치**가 된다. 저장본 삭제 가능.
- 서버 전송이 밀려 있으면 도구줄에 "저장 대기" 표시, 연결되면 자동으로 다시 보낸다.

## 4. 무작위 배치

### 4.1 규칙 (기기에서 계산, 0.1초 이내)

1. 고정석은 그대로, 나머지 책상과(고정되지 않은) 학생만 섞는다. 자리 없는 학생도 포함해 책상 수만큼 앉힌다.
2. **같은 자리 피하기**: 기준 배치(불러온 저장본, 없으면 무작위 직전의 화면)와 같은 책상에 같은 학생이 앉지 않게 한다.
3. **떨어뜨릴 학생**: 쌍은 상하좌우로 이웃하지 않는다. 이웃 = 같은 행 옆 칸 또는 같은 열 앞뒤 칸이면서 둘 다 책상. 두 자리씩 붙이기가 켜져 있으면 통로를 사이에 둔 칸은 이웃이 아니다.
4. 방법: 섞은 뒤 규칙을 어긴 학생을 다른 자리와 맞바꾸기를 반복(최대 수천 번). 다 못 지키면 같은 자리 피하기를 먼저 풀고 "N명은 같은 자리예요"라고 알린다. 떨어뜨릴 쌍을 지킬 수 없으면 "떨어뜨릴 수 없는 쌍이 있어요"라고 알린다.
5. 순수 함수(`web/seatlogic.js`)로 분리하고 `node --test`로 검사한다: 고정 유지, 같은 자리 회피, 쌍 분리, 자리 부족, 통로 이웃 규칙.

### 4.2 전체 화면 공개

- 결과는 시작 전에 이미 계산되어 있고, 애니메이션은 공개만 한다.
- 확인창: 적용 규칙 요약, **연출(슬롯머신 / 자석)**, **속도(빠르게 ≈5초 / 보통 ≈12초 / 한 명씩 = 스페이스·클릭)**, 효과음 켜기/끄기(Web Audio로 만든 짧은 소리, 파일 없음). 마지막 선택을 기억한다.
- 학생 보기로 크게, 전체 화면(Fullscreen API). 고정석은 처음부터 앉아 있다.
  - **슬롯머신**: 자리마다 이름이 돌다가 앞줄부터 하나씩 멈춘다.
  - **자석**: 이름 자석이 흩어졌다가 스포트라이트와 함께 한 명씩 날아와 붙는다.
- 끝나면 **이대로 확정 / 다시 섞기 / 닫기**. 확정하면 작업본에 반영(자동 저장), 저장 목록에는 "저장"을 눌러야 들어간다.
- `prefers-reduced-motion`이면 애니메이션 없이 바로 보여 준다.

## 5. 인쇄

- A4 가로 한 장(`@page { size: A4 landscape }`), 좌석이 꽉 차게 칸 크기를 계산한다.
- 인쇄 화면에서 **상단 문구 / 하단 문구**를 바로 고친다(작업본과 함께 저장).
- 학생 보기 / 교사 보기 중 골라 인쇄. 흰 바탕, 검은 테두리, 교탁은 "교탁" 글자만.

## 6. 데이터

### 6.1 시트 `Seats`

| 칸 | 내용 |
|---|---|
| id | 작업본은 `cur:{classId}`, 저장본은 무작위 id |
| classId | 클래스 |
| name | 저장본 이름(작업본은 빈칸) |
| layout | JSON 문자열 (아래) |
| updated | ISO 시각(나중 것이 이김) |

layout JSON: `{ rows, cols, desks: [bool], pairs: bool, assign: { "칸번호": studentId }, fixed: [칸번호], apart: [[sid, sid]], top: "", bottom: "", base: "저장본 id 또는 빈칸" }`. 칸번호 = 행 × cols + 열(0행 = 앞줄).

### 6.2 서버 경로 (교사 키)

- `seats {classId}` → 그 클래스의 작업본 + 저장본 목록(레이아웃 포함; 크기가 작다).
- `seatPut {classId, id, name, layout, updated}` → 같은 id면 덮어쓰기(더 새 `updated`만), 없으면 추가.
- `seatDel {id}` → 저장본 삭제.
- `createClass`가 `kind`를 받고 `classes`/`view`가 `kind`를 돌려준다.
- 학생 쪽 경로와 결과 캐시 버전(`bump_`)은 좌석 저장과 무관(학생 화면에 영향 없음).

### 6.3 기기 저장

- `localStorage` `seat:{classId}` = 작업본, `seats:{classId}` = 저장본 목록, `seatq:{classId}` = 아직 서버에 못 보낸 변경. 기기 저장 실패(사생활 모드 등)는 조용히 넘기고 서버 저장으로 이어간다.

## 7. 파일

- `gas/Seats.js` 새로: 경로 3개. `gas/Db.js`: `Seats` 헤더, `Classes.kind`, 스키마 버전 올림. `gas/Api.js`: kind, 경로 등록.
- `web/seatlogic.js` 새로(순수): 이웃 계산, `arrange()`, 구성 변경 시 배치 정리. `test/seat.test.mjs`.
- `web/seats.js` 새로: 좌석 화면(두 단계, 보기, 끌어다 놓기, 메뉴, 패널, 저장/불러오기, 동기화, 인쇄).
- `web/seatshow.js` 새로: 전체 화면 공개(슬롯머신·자석·효과음).
- `web/teacher.js`: 사이드바 묶음, 종류별 탭, 새 클래스 대화상자에 종류, "반" → "클래스" 문구.
- `web/styles.css`: 좌석·공개·인쇄 스타일. 새 클래스 이름은 기존 이름과 겹치지 않게 `seat-` 접두어.
- `web/sw.js`: 캐시 버전과 새 파일 목록.

## 8. 하지 않는 것

짝 규칙, 앞자리 우선, 남녀 섞기, 학번으로 클래스 묶기, 학생 앱에서 자리 보기(나중에 검토).
